# BrainSync AI — Futuristic SaaS Landing Page

A production-style React + Vite + Tailwind CSS landing page concept for an imaginary AI developer tool.

## Stack

- React 19
- Vite
- Tailwind CSS v4
- Lucide React
- Inter typography

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Design direction

- Dark midnight-black canvas
- Neon violet/cyan accents
- Frosted glass navigation and cards
- Bento-style feature grid
- Subtle hover/micro-interactions
- Responsive mobile navigation
- Semantic sections and accessible buttons/links
- No single-file HTML implementation
